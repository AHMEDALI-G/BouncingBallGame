# 🎮 Unity Bouncing Ball Project

## 📌 About

This project is a simple 3D Bouncing Ball simulation developed using Unity. It demonstrates basic physics concepts and introduces the fundamentals of 3D game development.

## ✨ Features

* ⚽ 3D bouncing ball simulation
* 🌍 Gravity and physics-based movement
* 🔄 Collision detection and bouncing behavior
* 🎮 Basic Unity scene setup
* 🧩 Beginner-friendly game development project

## 🛠️ Technologies Used

* **Game Engine:** Unity
* **Programming Language:** C#
* **Physics System:** Unity Physics Engine

## 🚀 How to Run

1. Clone or download this repository.
2. Open Unity Hub.
3. Click **Add Project from Disk**.
4. Select the downloaded project folder.
5. Open the project in Unity.
6. Open the main scene and click **Play** to run the simulation.

## 🎯 Learning Objectives

* Understand Unity's physics system.
* Learn about gravity and collision detection.
* Explore 3D scenes and GameObjects.
* Practice basic Unity game development.
